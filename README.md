# Лабораторна робота №1. Створення класів та об'єктів у C#
**Дисципліна:** Об'єктно-орієнтоване програмування  
**Студент:** Глодовський Тарас  
**Варіант:** №8 (`Animal`)  

---

## Мета роботи
Ознайомитися з основами об'єктно-орієнтованого програмування на мові C#. Набути практичних навичок створення класів, оголошення приватних полів, публічних властивостей, конструкторів та методів, а також налаштування системи контролю версій Git і завантаження проєкту на GitHub.

---

## Хід виконання роботи

1. **Створення та налаштування проєкту:**
   - Створив кореневу папку `OOP-Hlodovskyi`.
   - За допомогою командного рядка та .NET CLI згенерував новий консольний проєкт `lab1v8` командою `dotnet new console -o lab1v8`.

2. **Реалізація класу `Animal` (Варіант 8):**
   - У файлі `Program.cs` реалізував клас `Animal`, який містить:
     - **Приватні поля:** `_species` (вид), `_nickname` (кличка), `_age` (вік).
     - **Публічні властивості:** `Species`, `Nickname`, `Age` (з перевіркою некоректного від'ємного віку).
     - **Конструктор:** для зручної ініціалізації об'єктів при створенні.
     - **Метод `Speak()`:** виводить у консоль повідомлення про те, що тварина видає звук, а також метод `PrintInfo()` для виводу повної інформації.

3. **Робота з об'єктами:**
   - У методі `Main` створив 3 об'єкти тварин (собака, кіт, папуга).
   - Викликав їхні методи та продемонстрував успішну роботу програми в консолі.

4. **Контроль версій (Git & GitHub):**
   - Створив файл `.gitignore` у корені проєкту для ігнорування системних папок `bin/`, `obj/` та налаштувань IDE.
   - Ініціалізував локальний репозиторій Git, підключив віддалений репозиторій GitHub та зробив коміти.
   - Відправив готову роботу на GitHub у гілку `main`.
